# ADR-0001: 使用 useReducer 管理状态

## 状态

已接受

## 上下文

Todo 应用需要管理复杂的状态变更逻辑，包括添加、删除、编辑、切换完成状态、筛选和撤销功能。需要选择合适的状态管理方案。

## 决策

使用 React 的 `useReducer` 集中管理所有状态变更。

### 理由

1. **集中管理**：所有状态变更逻辑集中在 reducer 中，便于理解和维护
2. **便于测试**：reducer 是纯函数，易于单元测试
3. **撤销支持**：使用命令模式，undo stack 可以轻松集成
4. **无需外部依赖**：减少包体积，降低复杂度

### 替代方案

- **多个 useState**：状态分散，难以管理复杂交互
- **外部状态库（Zustand/Jotai）**：增加依赖，对于本地状态过于复杂

## 后果

- 所有状态变更必须通过 dispatch 触发
- 新增功能需要定义新的 action 类型
- 组件需要通过 props 或 context 接收状态和 dispatch
